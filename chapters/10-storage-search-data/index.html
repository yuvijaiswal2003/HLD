Remember for the interview

  1. 01Block storage is a raw disk for one host, file storage is a shared POSIX tree, object storage is an HTTP key to blob store that scales without limit and is cheapest per GB.
  2. 02Object stores split a strongly consistent metadata service from a bulk data service; durability comes from multi-zone placement, checksums, scrubbing and fast repair.
  3. 033x replication costs 200% overhead and survives 2 losses; RS(6,3) erasure coding costs 50% and survives any 3, at the price of CPU and costly repairs. Replicate hot data, erasure-code cold data.
  4. 04Upload large media straight from the client to object storage with presigned URLs and multipart upload; your servers only handle metadata.
  5. 05An inverted index maps each analyzed term to a sorted postings list; queries intersect lists, and positions enable phrase matching.
  6. 06BM25 is the default relevance function: IDF weighting, saturating term frequency and document-length normalization.
  7. 07Elasticsearch is near-real-time (refresh about every 1 s), routes documents by hash modulo a fixed primary shard count, and should be fed from the database by CDC, never treated as the source of truth.
  8. 08Use event time, not processing time, for windowed aggregation; watermarks decide when a window is complete and how late data is handled.
  9. 09Tumbling windows do not overlap, sliding windows put each event in size/slide windows, session windows close after an inactivity gap.
  10. 10Columnar storage reads only the columns a query touches and compresses well, which is why OLAP engines and Parquet use it; ELT on a lakehouse is the modern default.
